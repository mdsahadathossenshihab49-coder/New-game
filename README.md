# CyberRelics Match 🎮

A cyber-futuristic 3D tile matching game built for Android with high-performance audio-visual feedback, synth soundscapes, and intuitive touch controls.

---

## 📥 How to Download APK on Android Phone (কীভাবে ফোনে ইনস্টল করবেন)

1. এই GitHub পেজের ডানপাশে (অথবা মোবাইলে নিচে স্ক্রোল করে) **Releases** সেকশনে যান।
2. সর্বশেষ রিলিজটিতে ট্যাপ করে **Assets** এর নিচে থাকা **`CyberRelics-Match.apk`** ফাইলটিতে ক্লিক করুন।
3. আপনার ফোনে সরাসরি APK ডাউনলোড শুরু হবে।
4. ডাউনলোড শেষে ফাইলে ট্যাপ করে **Install** নির্বাচন করুন (যদি "Unknown sources" অনুমতি চায়, তা Allow করে দিন)।

## 🛠️ Build & Development
- **Framework:** Android Native (Jetpack Compose & Hardware-tuned Canvas WebView)
- **Language:** Kotlin, Web Audio & HTML5 Canvas
- **Gradle Command:** `./gradlew assembleDebug`
